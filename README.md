# Alumni Connect
Verified, institution-only alumni network: mentorship matching, referral tracking, interview library, career paths, events with check-in, chat, giving, resume match, points, admin analytics.
## Run
    npm install
    npm start        # http://localhost:3000
Admin: admin@portal.local / admin123. Email OTP is printed in the server console (demo mode).
Optional env: COLLEGE_DOMAIN=muj.manipal.edu (restrict sign-up), JWT_SECRET=...
## GitHub
    git init && git add . && git commit -m "Alumni Connect v2"
    git remote add origin <your-repo-url> && git push -u origin main
